Penjelasan Fitur Bagian C

Pada Bagian C, program dikembangkan dengan menambahkan fitur pendukung pengelolaan karakter, seperti menghitung rata-rata level, mencari karakter berdasarkan tipe, dan menemukan karakter dengan attack tertinggi.

Method getAverageLevel() menjumlahkan level semua karakter, kemudian membaginya dengan jumlah karakter. Method ini mengembalikan 0.0 apabila belum ada karakter agar program tidak melakukan pembagian dengan nol.

Method findByType() menghasilkan daftar baru yang berisi karakter dengan tipe yang sesuai. Jika tipe yang diberikan bernilai null, method mengembalikan daftar kosong.

Method findStrongest() mencari karakter dengan attack tertinggi dan mengembalikan null jika belum ada karakter. Fitur-fitur tersebut membuat pengelolaan karakter lebih praktis dan membantu menerapkan konsep enkapsulasi serta pengelolaan objek dalam Java.
